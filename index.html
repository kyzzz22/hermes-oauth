Hermes Agent

个人使用的本地自动化程序 / A personal, local-only automation app

这个应用是什么

Hermes Agent 是运行在本人 Windows 电脑上的个人 AI 助手。它通过 Google OAuth 访问本人自己的 Gmail 与 Google 日历，用于：

  • 按主题给收到的邮件打标签（只加标签，不删除、不标记已读）
  • 为确实需要回复的邮件生成草稿（不发送，由本人审阅后自行发送）
  • 把邮件里明确的会议／面试／截止时间写入本人日历
  • 把推广类邮件移出收件箱（保留在「所有邮件」中，可随时找回）

谁在使用

只有账号持有人本人。本应用不对外提供服务，不注册公众用户，没有任何第三方使用者。 授权账号为本人名下的三个 Gmail 账号。

数据怎么处理

所有数据只在本机处理与保存，不上传到任何外部服务器。详见 隐私政策。
